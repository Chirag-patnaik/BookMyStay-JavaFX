🏨 Book My Stay – Hotel Booking Management System

A JavaFX-based hotel booking application developed using **Java and JavaFX**.

✨ Features

* 🏨 Single, Double & Suite Rooms
* 📅 Room Booking & Reservation Management
* 🔍 Search Available Rooms
* 🛎️ Add-On Services
* 📋 Booking History
* ❌ Cancel Booking
* 📊 Booking Reports
* ⚡ Concurrent Booking using Threads
* 💾 Data Persistence using File Serialization

🛠️ Technologies

* Java
* JavaFX
* OOP
* Collections
* Multithreading
* File Handling
* Object Serialization

📁 Structure

text
src/
├── model/
├── service/
├── ui/
├── styles/
└── Main.java
```

🚀 How to Run

1. Install Java JDK and JavaFX SDK.
2. Open the project in VS Code.
3. Configure the JavaFX SDK path.
4. Run `Main.java`.
